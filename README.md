# MindLink AI

Build a premium, modern web application for an AI personal-brand platform.

PRODUCT CONCEPT

The platform allows influencers, creators, experts, coaches, educators, founders, consultants, and other personal brands to create their own AI character.

Each AI character represents the creator's approved knowledge, communication style, expertise, personality, and rules.

Audience members can discover AI characters, create an account, chat with them, and talk to them through browser-based voice calling.

The product is NOT positioned as a generic AI chatbot.

It is an AI-powered personal-brand interaction marketplace.

Core message:

"Meet the AI behind people you trust."

The experience should feel premium, trustworthy, modern, human, and slightly futuristic.

IMPORTANT:

This is FRONTEND ONLY for now.

Do NOT connect Supabase yet.

IMPORTANT PRODUCT PRINCIPLES

==================================================

1. The creator is the product.

AI should enhance the creator's presence, not replace the creator.

2. Make the AI character feel trustworthy.

3. Make voice calling feel like "talking to the creator's AI character", not calling a phone number.

4. The platform should feel like a marketplace of trusted expertise.

5. Never make it look like a generic ChatGPT clone.

6. The interface should work equally well for:

- Instagram creators

- YouTube creators

- LinkedIn experts

- Coaches

- Consultants

- Educators

- Founders

- Entrepreneurs

7. Clearly distinguish AI from the real human.

8. Use fictional/demo creator data for the prototype.
